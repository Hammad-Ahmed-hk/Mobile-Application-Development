# Mobile Application Development

Lab tasks and projects for the Mobile Application Development course (B.Sc. Software Engineering, University of Azad Jammu & Kashmir), built with **Kotlin** and **Jetpack Compose** in Android Studio.

## Labs

| Lab | Topic | Contents |
|---|---|---|
| [Lab 01](Lab_01) | Android Studio setup and first app | Report: installing Android Studio, creating the emulator, running `MyFirstApp` |
| [Lab 02](Lab_02) | Project structure and Campus Event Card | Report and Gradle build file: project inspection, string resources, reusable composables, previews |
| [Lab 03](Lab_03) | Student Registration form | Complete Android app, unit tests and report: Compose form controls, validation, state handling |

## Run an app

1. Install the latest stable **Android Studio**.
2. Open the lab folder (for example `Lab_03`) with **File → Open**.
3. Let Gradle sync, then run on an emulator or a device (minSdk 24, Android 7.0+).

Each lab folder is its own Gradle project. `local.properties` is machine-specific and is not committed.
